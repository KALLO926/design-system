# 配色调研（2026-11-24，kk 点名「关于配色可以去调研下」）

起因：kk 明令禁止墨绿、米黄等 AI 常用色（已入契约「颜色」节）后，要求就配色做一轮调研。本报告只收一手来源与可操作结论，观察与候选规则分开标注。

## 一、为什么 AI 总滑回墨绿米黄（机制）

- 模型输出的是训练分布的众数：自然/食品/手作类目里，「森林绿＋奶油色」是最高频的高级感组合，无外部约束时必然收敛到类目平均脸——与瑞士网格同属模板默认，只是换了层皮。
- 按 HSL/直觉调色会放大此问题：「把饱和度压低求高级」的最短路径就是深绿与暖米黄；HSL 的明度不感知均匀（黄色显亮、蓝色显暗），手工拉阶中间调容易发灰发闷。
- 推论：靠「下次小心」无效，必须给配色上可测的约束（见第四节候选规则）。

## 二、专业配色系统怎么做（三个一手来源）

### Radix Colors（radix-ui.com/colors 官方文档，2026-11-24 抓取核实）
- 色板不是「一组好看的颜色」，而是 **12 级功能阶梯**，每一级对应一个用途：
  1 应用底 / 2 微底 / 3 组件底 / 4 悬停底 / 5 按下·选中底 / 6 弱边框 / 7 边框·焦点环 / 8 悬停边框 / 9 实色 / 10 悬停实色 / 11 低对比文字 / 12 高对比文字。
- 纪律：先定用途再选色；文字用 11/12 级而不是纯黑（纯黑对比过猛、与底色无亲缘）。
- 选品牌阶先分「为白字设计」还是「为深字设计」两组清单（如 sky/mint/lime/yellow 只能配深字），选错组对比必然翻车。
- 自定义色板生成器：给一个底色，它补全 12 级且保持与官方阶相近的对比关系。

### Adobe Leonardo（leonardocolor.io / github.com/adobe/leonardo）
- 反向生成：**先定目标对比度，再生成颜色**——色板是「对比度契约」的产物，不是手挑色值。
- 整板可按色盲安全自动重排；可按目标明度与目标对比双控。
- 与本机既有纪律互证：契约已有的「正文 ≥4.5:1、状态 ≥3:1、交付前成对实测」就是同一思路，Leonardo 把它前置到生成环节。

### OKLCH 感知均匀色彩空间（Evil Martians《OKLCH in CSS》2025-09；Atmos 术语库）
- `oklch(L C H)`：L 是感知明度（0–1），跨色相一致——同一 L 值在任何色相看起来一样亮，HSL 做不到。
- 生成色阶的正确姿势：固定 H 与 C，只让 L 等步进；深/浅两端收 C 防脏。
- CSS 相对色 `oklch(from <种子色> ...)` 可从一个种子色派生整套状态色，保证同族同源。

## 三、从资产取色（颜色归属）

- Distinctive BAT 的品牌资产研究：近 100 个单色/组合里只有 2 个能达到 50% 品牌归属（如 Cadbury 紫）——颜色成为资产靠**单一颜色＋长期重复**，不靠配得丰富。
- 与契约现行条互证：以主题与自有资产取色为准；从包装/产品/摄影采样得到的色值有出处，凭感觉编的色没有归属、也最容易滑回平均脸。

## 四、可直接用的操作清单（下个设计任务起执行）

1. 开工先写 **7 格色板功能表**（对照 Radix 阶梯查漏，L1a+ 交付必附）：

| 功能槽位 | OKLCH / Hex | 彩度 C / 对比度实测 | 出处说明（强调色必写资产采样部位） |
|---|---|---|---|
| 1. 应用底（Page BG） | | `C ≤ 0.02` | |
| 2. 微底（Subtle Surface） | | `C ≤ 0.02` | |
| 3. 组件底（Component Surface） | | `C ≤ 0.02` | |
| 4. 边框 / 焦点环（Border / Focus） | | 对相邻面 `≥ 3:1` | |
| 5. 强调实色（Accent CTA） | | 载字 `≥ 4.5:1` | 采样自：`<资产与部位>` |
| 6. 低对比文字（Muted Text） | | 对底 `≥ 4.5:1` | |
| 7. 高对比文字（Primary Text） | | 对底 `≥ 4.5:1` | |

2. 色阶一律用 OKLCH 生成：种子色定 H，L 等步进，C 两端收；状态色用相对色从种子派生，不逐个手挑。
3. 强调色从资产采样，交付时注明采样出处（哪个资产、哪个部位）。
4. 对比在生成时验：正文 ≥4.5:1、状态 ≥3:1，不合格只动 L、不换色相。

## 五、候选规则（未入契约，按晋升规则等 kk 拍板或项目验证）

- **中性阶彩度上限**：用 OKLCH 的 C 值给「染色过量」上可测判据——中性阶（底、文字、弱分割）C 超过约 0.02 即视为染色过量，与契约现行「一眼叫得出绿/黄色名即违规」并用：一个主观速判、一个数值复核。墨绿/米黄的本质正是中性阶彩度过大且色相落进绿/黄区间。
- **色板功能表交付**：L1+ 设计交付时附色板功能表（第四节第 1 条），缺格即未完成。
