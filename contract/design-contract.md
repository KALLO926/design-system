# 设计判断契约（自学习与设计产出共用 · v2.3 精简版）

定位：kk 的审美判断正本。每日自学习与一切设计产出开工前必读；与其他技能或文档冲突时以本契约为准（kk 当场指令除外）。
治理口径：本文件只收已成立的审美与验收判定；流程与 CLI 细则归 `master/design-system-master_v2.3.md`，待验证观察归 `contract/design-lessons.md`，否决详述归 `contract/design-anti-examples.md`。
容量纪律：上限 **≤95 行且 ≤4,500 字**，单行简洁清晰、严禁多条强塞单行。

## 总纲
- **三词纪律**：克制（无关的再好看也不上）、编排（先定视线顺序与疏密节奏）、重心与让步（每屏只有一个视觉重心，其余变小、变淡、退后）。
- **先资产后版式**：赢家赢在不可复制的资产（包装、人物、自有字体、真实摄影），版式只是入场券。
- **开工声明与不及格线（L1+ 必做）**：动手前写死四栏——视觉锚点、第一眼唯一核心焦点、方向来源、**可判定的不及格线**（含 `内库引用`）；写不出唯一焦点或不及格线不许开工。
- **取消默认脸**：网格＋无衬线不再是兜底；方向稿须在骨架/字体/排版/色彩/质感中至少三项实质分化，只换配色不算新方向。
- **学习目的**：内化判断并重新推导，禁止原样搬运参考站的数值、版式与构图。

## 硬禁区（命中即不交付）
- **PPT 式设计**：禁止一节一页横条带堆叠、居中大标题＋卡片阵列、区块同构互不衔接；按连续滚动空间编排。
- **大色块铺底分段**：禁止整幅色带/图片带/大面积满铺底色分段，分段靠留白＋发丝线。窄口例外：全页仅许一处整幅深色带作唯一节奏转折且目的明确。
- **纸面/档案/复古纸质风**：米黄纸面底、做旧纹理、发丝线标本气质一律禁止（2026-10-21 kk 明令）。
- **AI 常用色禁令**：墨绿、米黄（奶油/米色系）及近似深绿、暖米色调禁止用作底色与主色调；判定＝底面或主色单看一眼能叫出绿/黄色名即违规（产品实物与实拍包装本身颜色不限，2026-11-24 kk 明令）。
- **首屏多层拦截**：公告条＋弹窗＋Cookie 横幅＋聊天按钮同抢首屏一律禁止。
- **网红模板三件套与纯装饰**：蓝紫/青紫渐变＋弥散光晕＋大圆角阴影卡片阵列非品牌点名禁成套；悬浮图标、无意义徽章堆砌、占位插画填空同禁。
- **自审当验收**：制作方自评分不作数，禁止写入交付报告。

## 空间与留白
- 留白＝真空白（连底色都不涂）；空白要成片（段间参考 200–400px），靠密空交替建节奏，不摊成均匀小缝。
- 密度默认做减法：每屏只留一个主角，先删一半缺了再加；空场需与构图同算，防止单侧留白被读成内容不足。
- 间距按 4/8px 步进、无魔法数字；区块间留白 ＞ 区块内间距 2 倍，分组靠距离不靠框线与底色。

## 形状与质感
- **形状**：方向阶段定死且全站成系（直角成系或圆润成系），禁止用 CSS 默认值凑合；全站圆角由单一 CSS 变量按比例派生（token 化）。
- **照片三待遇**：整幅出血、大圆角、抠图无框；禁止影棚照切矩形硬贴底色。
- **质感**：从产品材质长出，全站只许一种主质感，禁止另贴无关噪点/玻璃/纸感；廉价感先查塑料高光与假反光。

## 颜色
- 以主题与自有资产取色为准；外部规则库无配色决定权，食品/消费品慎用高饱和品红等违和科技色。
- **全页一底到底**：默认纯白或品牌定版底，不中途换底分段；中性色占比 ≥85%，强调色只许 1 个且仅用于核心 CTA 与关键状态。
- **底面彩度上限**：底面中性阶 OKLCH 彩度 `C ≤ 0.02`，文字与细线不限（2026-11-25 kk 拍板修正）。
- **色板功能表（L1+ 必附）**：按 7 格功能表（底/微底/组件底/边框/实色/低对比字/高对比字）生成 OKLCH 色阶，强调色须注明资产采样出处。

## 排版、容器与状态
- **排版**：字体家族 ≤2；正文左对齐（极短标题除外）；层级靠字重、字号比、灰度拉开，不靠彩色字；英文 UI 标签默认 Sentence case。
- **容器**：能用排版与间距分组不上容器，卡片嵌套 ≤2 层。
- **状态可读**：选中/勾选/按下对比 ≥3:1，靠整块填充、完整描边或字重变化，不靠淡色或单侧竖条；禁用态全站统一（默认 `opacity: 0.5`）。
- **焦点与错误**：键盘焦点必有独立焦点环（`:focus-visible`），鼠标点击不带环；错误态用唯一警示色且只长在边框与文字上，不铺底。
- **对比底线**：真实浏览器实测正文 ≥4.5:1，状态填充/控件边/焦点环 ≥3:1。

## 动效
- 动效只解释状态变化或叙事节奏，禁纯装饰漂浮/弹跳/循环晃动；全站只许一种缓动性格（硬切/极慢位移/弹簧，方向阶段定死）。
- 滚动叙事采用进度分段映射＋统一弹簧；须提供 `prefers-reduced-motion` 静态等价态；视频 Hero 压字须逐帧验可读或加固定遮罩。

## 素材与资产
- **素材优先级**：实拍 ＞ 授权图库（Openverse/Wikimedia CC＋页脚署名）＞ AI 生成 ＞ 代码绘图（最后手段）；禁无授权外链与盗图。
- **素材等级定验收上限**：虚构品牌开工前须先用 AI 生成整套包装/产品资产当主角；同一产品多配色须拿母版改色，禁止分别生成。
- **生成图质检**：整套图须将主体识别特征写进每张提示词并逐张验图；AI 人物忌过幼与塑料感（成人 3 头身比例、窄眼粗眉、哑光去腮红）。
- **字体自托管（含单文件降级）**：工程项目零外链字体；单文件 `.html` 交付时英文字体可子集化 Base64 内联，中文字体或大体积字体降级为系统无衬线字体栈，禁内联整包中文字体。

## 调研与验收
- **调研铁律**：必看官网本体、逐张验图、核对域名身份；量测制必记可量测数据（色值占比、字阶比、图片首屏占比、密度、圆角/间距）并逐项对进成品。
- **四道验收门（L1+ 必过）**：
  1. 制作方减法自查（删装饰/扩留白/压噪音/对反例库）；
  2. **工艺双闸门前置**：`impeccable` 机检零 P0 ＋ `unslop`（`signs.md` + `tokens.md`）Token 级工艺审计；
  3. **受控盲审**：无过程上下文子 Agent 仅看默认态桌面＋手机截图，注入 ≤30 行《评审标尺包》（含本次焦点/不及格线/反例红线）；设计 ＜7 或命中 P0（含多图主体不一致、压字不可读）不放行；返工熔断上限 2–3 轮；
  4. **状态抽查**：制作方实测 hover/focus/selected/disabled 四态＋键盘 Tab 路径；数据界面须附空态/加载态/错误态截图。

## 可机检红线索引（优先由脚本/前置门拦截，不靠文字兜底）
- 底面中性阶 OKLCH `C > 0.02`、绿/黄色相底色、整幅深色带 `> 1` 处、外链字体请求、离阶字号/过重字重（`600` 滥用）/超时入场（`>0.5s`）、`:focus-visible` 缺失、正文/状态对比度不达标。

## 晋升规则（写入纪律）
1. kk 本人判定（点赞/否决/纠正/明令）→ 当轮直入本文件并标日期；否决同步入反例库（两处合为 Veto Log）。
2. 自学习结论 → 先记 `design-lessons.md`，同类二次互证或经项目验证后晋升本文件；已晋升条目同步归档。
3. 与本契约冲突 → 当轮标「待裁决」等 kk 拍板，不擅自改写。
4. 守住双上限（≤95 行、≤4,500 字），过时与已代码化条目及时精简。
