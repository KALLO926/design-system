# 设计体系总纲 · 实战工作流与自学习（v2.3 优化版）

版本：2026-11-25 v2.3（基于 v2.2 源码级审计重构：四步纯净流水线、工艺双闸门前置、受控盲审标尺包、L1a/L1b 分级、学习降频与消费闭环）
定位：本文件为流程、分级、模板与工具操作元规则总纲；审美与验收红线以 `contract/design-contract.md` 为唯一正本，冲突时以契约为准。

## 一、体系架构与顶层纪律

两大引擎通过**共享中枢（`contract/` 契约＋教训＋反例 + `patterns/` 模式库 + `research/` 调研资产）**咬合运转：
1. **判断唯一正本**：`contract/design-contract.md`；kk 当场指令高于一切成文规则。
2. **第三方技能统一挂载 `LOCAL-NOTE.md`**：上游 `SKILL.md` 保持原样便于升级，所有本地定位与契约冲突覆写写入同目录 `LOCAL-NOTE.md` 与 `skills/SKILLS-ROUTING.md`。
3. **判分与制作分离，但标尺必须对齐**：制作方自评分不作数；视觉验收走**无过程上下文、带 30 行标尺包**的受控盲审；kk 的眼睛是最终否决。
4. **验证优先于交付**：未通过工艺双闸门（机检＋Token 审计）与真实运行/截图验证，不得宣称完成。

## 二、实战工作流（四级分级 + 四步纯净流水线）

### 2.1 四级任务分级

| 级别 | 适用范围 | 必须走的步骤 | 可跳过 / 降本规则 |
|---|---|---|---|
| **L0 小修/微调** | 改文案、调间距、修局部 Bug、微调已有组件 | 读契约 → 修改 → 减法自查＋工艺双闸门 → 交付 | 方向稿、全量调研、盲审 |
| **L1a 体系内延展** | 已有明确视觉语言/母版的新页面或功能页 | 查内库 → 开工声明 → 复用母版制作 → 工艺双闸门 → 单轮受控盲审 → 交付 | 联想探索、三方向稿 |
| **L1b 常规新设计** | 无现成母版的单页、功能模块、组件重构 | 查内库 → 开工声明 → **2 个实质分化方向切片** → 选定后铺全页 → 全门验收 | 免做 3 版全页，方向稿仅做「首屏＋1 个核心区」高保真切片 |
| **L2 旗舰/全新** | 全新品牌、大型官网、从零建视觉体系 | 完整流程：查内库＋联想探索 → **3 个实质分化方向切片** → 全量资产盘点 → 全门验收 | 可派生一份 `DESIGN.md` 便携简报（仅作简报，不当唯一上下文） |

### 2.2 开工前固定动作（查内库 + 开工声明 + 7 格色板）

1. **查内库（≤1 分钟，L1a+ 必做）**：先检索 `patterns/README.md`、`research/component-recipes-2026-11-20.md`（避开标注 `⚠️ 契约高危` 的未点名卡）与 Open Design 存档。
2. **填写《开工声明 v2》（L1a+ 必做，写不出唯一焦点或不及格线不许开工）**：

```markdown
## 开工声明
- 任务级别：L1a / L1b / L2
- 视觉锚点：<一句话定画面主体与材质世界>
- 第一眼唯一核心焦点：<首屏唯一落点>
- 方向来源：<联想母题 / kk 指定风格锚>
- 内库引用：<引用的 patterns/、做法卡编号或 Open Design 包，无匹配填“无”>
- 不及格线（可判定）：<至少 2 条明确不及格标准，不写感觉词>
```

3. **L1a+ 7 格色板功能表（出自 `research/color-research-2026-11-24.md`，OKLCH 生成）**：

| 功能槽位 | OKLCH / Hex | 彩度 C / 对比度校验 | 来源说明（强调色须写资产采样部位） |
|---|---|---|---|
| 1. 应用底（Page BG） | | `C ≤ 0.02` | |
| 2. 微底（Subtle Surface） | | `C ≤ 0.02` | |
| 3. 组件底（Component Surface） | | `C ≤ 0.02` | |
| 4. 边框 / 焦点环（Border / Focus） | | 对相邻面 `≥ 3:1` | |
| 5. 强调实色（Accent CTA） | | 载字 `≥ 4.5:1` | 采样自：<资产部位> |
| 6. 低对比文字（Muted Text） | | 对底 `≥ 4.5:1` | |
| 7. 高对比文字（Primary Text） | | 对底 `≥ 4.5:1` | |

4. **联想探索（L1b/L2 方向生成法）**：从品牌名、符号、产品能力、场景、文化背景提线索，沿自然/艺术/科学/技术/情感多层转译为构图、材质、字体、色彩、空间、动效母题；三方向切片须在骨架/字体/排版/色彩/质感中至少三项实质分化；方向确认后立即停止发散。

### 2.3 四步纯净流水线（机检与 Token 审计前置）

> 详细技能覆写见 `skills/SKILLS-ROUTING.md` 及各技能 `LOCAL-NOTE.md`。

| 步 | 环节 | 使用技能 / 工具 | 核心职责与冲突隔离 |
|---|---|---|---|
| **1** | **定向与原型** | `frontend-design`（主）＋ `gemini-frontend-design`（Hero 4 原型＋3 字号纪律，禁用其 `forest` 绿底建议） | 定视觉方向、骨架、几何与唯一缓动性格；**已移除 `taste-skill`（避免 PPT 一屏一节与沙/绿底发牌）与 `ui-ux-pro-max`（降为点名查 UX/图表词典）** |
| **2** | **制作与减法自查** | 制作方按契约实现 | 全页一底到底、先盘资产再排布；减法四查（删装饰、扩留白 20–30%、压噪音、核反例库） |
| **3** | **工艺双闸门（前置！）** | `impeccable` **仅检测器 Hook/脚本**（P0 阻断）＋ `unslop`（**仅 `signs.md` + `tokens.md` 审计表**） | **先跑最便宜的确定性与 Token 审计**：拦截对比度、焦环、OKLCH 彩度、外链字体、离阶字号、`600` 字重滥用、超时动效；**未过原地返修，不进第 4 步**。纯文档镜像环境无 `impeccable` 二进制时，以 `unslop` 清单＋人工实测替代 |
| **4** | **语义审核 + 受控盲审** | `better-interface`（唯一后段审查入口，吸收 `web-design-guidelines` 独有工程项）＋ **带标尺包盲审子 Agent** | `better-interface` 按“删减→原生→复用”输出证据级报告；盲审隔离制作过程但注入 ≤30 行《评审标尺包》 |

**仲裁序位**：`impeccable` 机械事实＋`unslop` Token 硬红线（P0 阻断）＞ `better-interface` 高危触发器与工程/无障碍底线（P1 必改或留痕豁免）＞ `better-interface` 审美建议（CANDIDATE，仅采高价值项）。

### 2.4 受控盲审标尺包（≤30 行，随默认态截图一并注入盲审子 Agent）

```markdown
## 受控盲审标尺包（隔离制作对话与源码，仅给标尺与默认态桌面+手机截图）
- 本次视觉锚点：<复制开工声明>
- 第一眼唯一核心焦点：<复制开工声明>
- 本次不及格线：<复制开工声明>
- 硬禁区 P0 红线（任一命中不放行）：
  1. 纸面/档案风、PPT 式横带堆叠、大色块分段（全页深色带 >1 处）
  2. 墨绿/米黄/奶油/暖米作底色或主色调（实物实拍本身除外）
  3. 网红三件套（蓝紫渐变＋弥散光晕＋阴影卡阵）与纯装饰填充
  4. 多图主体不一致、压图/压视频文字不可读、主体资产缺席
- 打分门禁：设计 / 可用性 / 创意 / 内容；设计 < 7 或命中 P0 不放行；返工熔断上限 2–3 轮，达上限停审呈报 kk 拍板。
```

### 2.5 交付与回流
- **状态实测**：交付前制作方实测 hover/focus/selected/disabled 四态＋Tab 焦点路径＋真实浏览器对比度；数据界面必附空态/加载态/错误态截图。
- **双通道与防缓存**：单文件 `.html`（改版换 `_v2/_v3` 文件名，禁覆盖；中文字体降级系统栈防体积爆炸）＋ App Space 版；汇报先人话变化、后验证证据。
- **回流**：kk 判定当轮入契约（否决同步入反例库）；项目教训入 `contract/design-lessons.md`（每项目 ≤2 条）。

## 三、自学习体系与周五量化复盘

### 3.1 自学习运行节奏（降频提质 + 代码回跑门）
- **唯一方法**：`skills/ui-pattern-learner/SKILL.md`（Step 0 本地化 → Step 1 `designlang extract` 底稿＋`getComputedStyle` 强制复核四项 → Step 2 状态差值/DOM 考古 → Step 3 三问解剖 → Step 4 沙盒临摹＋分层盲审 → Step 5 沉淀完成报告＋**第 6 节落盘代码回跑校验**）。
- **每日节奏（建议配额）**：**每日 1 个深度对象走完整五步法入模式库** ＋ **2 个轻采样（只采 Token 差值与克制点记日志，或按本周项目缺口定向采风）**；若遇登录墙或资产不可复现，按 `research/learning-sources.md` 状态表直接跳过并回写状态，禁止空转。
- **工具细则（从契约迁入）**：整页/整站先用 `monolith` 本地化存档，再对 localhost 跑 `npx -y designlang extract <URL> --wait 3000 --motion-runtime`（重页面禁 `--interactions`）；`designlang` 的 `fidelity` 分与 `verify-ui` 禁用作验收；四项不可信字段（前景色归纳、字体归属、字阶主值、scrollLinked）必须 `getComputedStyle` 实测复核。

### 3.2 每周五复盘 4 项量化指标（`weekly-design-review` 必填）

| 指标 | 计算口径 | 阈值与触发动作 |
|---|---|---|
| **kk 一次通过率** | 未触发 Veto Log 交付数 ÷ 总交付数 | `< 70%` → 补齐盲审标尺包或反例库 |
| **盲审平均返工轮次** | 盲审总轮次 ÷ 经盲审任务数 | `> 1.5` 轮 → 将高频驳回项下沉至 `impeccable` 机检 |
| **规则代码化率** | 可机检红线数 ÷ 总硬红线数 | 持续提升，保证契约常留 `≥ 20` 行余量 |
| **内库消费率** | 《开工声明》含有效内库引用任务数 ÷ 本周任务数 | 连续 2 周 `< 30%` → 暂停泛化学习，优先优化索引 |
