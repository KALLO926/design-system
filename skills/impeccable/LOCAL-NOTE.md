# 本地定位说明（2026-11-25：拆分“前置机检门”与“点名全功能模式”）

- **现行定位（一分为二）**：
  1. **常驻流水线第 3 步（前置 P0 机检门）**：仅调用其底层 **detector binary / hook** 执行确定性机械检测（对比度、焦环、语义、布局溢出，及后续下沉的 OKLCH `C ≤ 0.02`、深色带计数、外链字体拦截等自定义规则）。**不在此步触发其 20+ 子命令全流程设计总监路由**，避免与第 1 步 `frontend-design` 及第 4 步 `better-interface` 争夺主导权。
  2. **点名全功能模式**：当面临复杂后台/工具（Operate/Read 模式）重设计或 kk 明确点名 `/impeccable <command>` 时，才按上游 `SKILL.md` 启用完整命令体系。
- **与旧版总纲的顺序纠偏**：本技能机检已从原第 6 步**前置到审查第 1 步（现第 3 步工艺双闸门）**，未过机检原地返修，绝不浪费后续 LLM 审查与盲审成本。
- **镜像环境降级方案**：本仓库镜像未收录 96MB 工具本体与 `reference/` 目录。无本地二进制时，外部 Agent 以 `skills/unslop/references/signs.md` + `tokens.md` 逐项审计 ＋ 真实浏览器 `getComputedStyle`/对比度实测作为第 3 步等效替代。
